# mswplayr icon exploration

Create one minimal, distinctive icon for a native video player. The app uses neutral black surfaces, compact controls, and Martian Grotesk. Avoid purple, gradients, ornamental shadows, typography in the icon, filmstrip perforations, and a stock play triangle inside a rounded square.

The first round explores twenty different constructions in a single neutral palette, so color cannot disguise weak geometry. Every concept is shown at a large size and at actual 16, 24, and 32 pixel sizes.

Judge criteria: recognizable silhouette, small-size legibility, useful connection to viewing or moving images, optical balance, and memorability. This design review is not trademark clearance.

Review provider requested by the user: Claude, model Claude Opus 5.5 (`claude-opus-5-5`). Each review is an independent delegated task.

Draft source and PNGs are in `concepts/`; `01-twenty-concepts.png` is the complete rough contact sheet. `scripts/icon-design/main.go` reproduces the drafts.
